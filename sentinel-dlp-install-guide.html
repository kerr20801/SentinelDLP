SentinelDLP

貼上任何東西前，自動掃描並消毒敏感資料。一鍵安裝，零設定。

🔒 資料不外傳 ⚡ 零安裝依賴 🌐 任何網站都有效
1

下載擴充套件

點擊下方連結下載 ZIP 檔，解壓縮到任意位置（例如桌面）。

💡 解壓縮後會得到一個 sentinel-dlp-kerr 資料夾，記住它的位置。
2

打開 Chrome 擴充套件管理頁

在 Chrome 網址列輸入以下網址，按 Enter：

chrome://extensions/
🌐 在 Chrome 網址列貼上並按 Enter
3

開啟「開發人員模式」

頁面右上角有一個「開發人員模式」的開關，把它打開。

ℹ️ 開啟後頁面上方會出現三個新按鈕，這是正常的。
🔧 右上角找到「開發人員模式」並打開
4

載入擴充套件

點擊左上角出現的「載入未封裝項目」按鈕，選擇剛才解壓縮的資料夾。

⚠️ 選擇的是資料夾（sentinel-dlp-kerr），不是 ZIP 檔。
📂 選擇解壓縮後的 sentinel-dlp-kerr 資料夾
5

完成！測試看看

安裝後右上角會出現 K 圖示。複製下面任一測試值，到任何網頁的輸入框貼上，看看是否彈出警告。

點一下複製，然後到任意網頁貼上：

AKIAIOSFODNN7EXAMPLE AWS Key
192.168.1.100 Private IP
ubuntu@10.0.0.1 SSH target
/home/ubuntu/server.key Linux path
ghp_abcdefghijklmnopqrstuvwxyz123456 GitHub Token
✅ 看到右上角彈出紅色警告框，顯示消毒後版本，就表示安裝成功！
